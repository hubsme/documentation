El frontend de Hubsme no llama endpoints directamente desde los componentes. En su lugar, usa un cliente tipado generado automaticamente desde el Swagger del backend, envuelto en servicios de dominio que inyectan la URL base y el token de sesion.

## Cliente generado

El archivo `src/api/backend.api.ts` se genera con `swagger-typescript-api` a partir del spec expuesto por el backend en `http://localhost:6001/api`. Contiene todas las interfaces DTO, parametros de query, cuerpos de peticion y respuestas tipadas.

<Info>
  Regenera el cliente cada vez que el backend cambie sus DTOs o rutas. El backend incluye el script `npm run generate:types` para producir este archivo.
</Info>

## Inyeccion de la URL base y autenticacion

La URL del backend se configura con la variable de entorno `NG_APP_BASE_URL` (por defecto `http://localhost:6001`). El `HttpClient` del cliente API recibe esta URL y un `securityWorker` que lee el token desde `localStorage`.

```ts
// src/app/app.config.ts (fragmento)
import { Api, HttpClient } from 'api/backend.api';
import { environment } from '@environment/environment';

new HttpClient({
  baseUrl: environment.baseUrl,
  securityWorker: async () => {
    const session = localStorage.getItem('user_session');
    if (session) {
      const token = JSON.parse(session).accessToken;
      return { headers: { Authorization: `Bearer ${token}` } };
    }
    return {};
  },
  customFetch: async (input, init) => {
    const response = await fetch(input, init);
    if (response.status === 401) {
      // redirige a login
    }
    return response;
  },
});
```

## Patron de uso

Los componentes inyectan el servicio de dominio, no el cliente `Api` directamente. Esto mantiene los componentes desacoplados del formato de respuesta del backend.

```ts
import { Component, inject } from '@angular/core';
import { MeetingService } from '@service/admin/meeting.service';

@Component({
  selector: 'app-meetings',
  templateUrl: './meetings.html',
})
export class Meetings {
  private meetingService = inject(MeetingService);

  async loadMeetings() {
    const meetings = await this.meetingService.findAll({ status: 'confirmed' });
    // meetings ya es response.data
  }
}
```

<Warning>
  No importes `Api` directamente en los componentes. Usa siempre el servicio de dominio correspondiente para mantener consistencia y facilitar pruebas unitarias.
</Warning>
