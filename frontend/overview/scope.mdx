El frontend de Hubsme es una aplicacion Angular 20.3 con Server-Side Rendering (SSR) mediante Express. Consume un backend NestJS a traves de un cliente API tipado generado automaticamente desde Swagger. La plataforma opera en la zona horaria de Peru (America/Lima, UTC-5) y conecta a PYMES con consultores especializados.

## Areas funcionales

La aplicacion se divide en cinco grandes areas, cada una con rutas y permisos especificos:

<CardGroup cols={2}>
  <Card title="Landing publica" icon="globe">

## Funcionalidades por rol

### PYME

- Realizar diagnosticos empresariales con IA
- Buscar y contratar consultores
- Agendar reuniones via Microsoft Teams
- Gestionar tareas y documentos
- Realizar pagos con Mercado Pago
- Invitar miembros al equipo

### Consultor

- Gestionar disponibilidad de calendario
- Ofrecer servicios especializados
- Atender reuniones con PYMES
- Registrar tareas y actas
- Ver ingresos y suscripcion

### Administrador de plataforma

- Gestionar codigos promocionales
- Supervisar PYMES y consultores
- Monitorear reuniones
- Atender tickets de soporte

<Note>
  El frontend usa `authGuard` para proteger rutas de PYME y consultor, y `adminAuthGuard` para el backoffice. La sesion se restaura desde `localStorage` mediante `SessionService` o `AdminSessionService`.
</Note>
